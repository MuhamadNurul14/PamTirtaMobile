# PAM Tirta Mobile

Aplikasi mobile berbasis Android untuk mendukung layanan dan pengelolaan informasi Perusahaan Air Minum (PAM) Tirta Kemuning.

## 📱 About Project

**PAM Tirta Mobile** merupakan project aplikasi Android yang dikembangkan menggunakan Android Studio. Project ini bertujuan untuk menyediakan platform mobile yang memudahkan pengguna dalam mengakses layanan dan informasi terkait PAM Tirta Kemuning.

## 🛠️ Tech Stack

- **IDE:** Android Studio
- **Language:** Kotlin / Java
- **Platform:** Android
- **Build System:** Gradle
- **Version Control:** Git & GitHub

## 📂 Project Structure

```text
PAMTirtaKemuning/

├── .gitignore

├── gradlew

```

## ⚙️ Installation

1. Clone repository:

   ```bash
   git clone https://github.com/MuhamadNurul14/PamTirtaMobile.git
   ```

2. Open the project using Android Studio.

3. Wait for Gradle Sync to finish.

4. Connect an Android device or start an emulator.

5. Run the application.
